**Markup.** Root `<div class="facade-container relative aspect-video w-full overflow-hidden rounded-card">`. Inside, in order:
1. `<Picture src={thumbnail} formats={['avif','webp']} widths={[480,720,960]} sizes="(min-width: 1024px) 512px, (min-width: 768px) 480px, 100vw" fit="cover" loading="lazy" alt="" class="absolute inset-0 h-full w-full object-cover object-[50%_22%]" />`. `alt=""` is correct — this thumbnail is decorative, the play button carries the accessible name. `loading="lazy"` and `fit="cover"` are both mandatory: lazy keeps the hero background as the LCP element, and `fit="cover"` is the Sharp upscale guard against the 1254px source. The `object-[50%_22%]` position keeps the subject in the 16:9 crop; the crop itself is done by `object-cover` inside the fixed `aspect-video` box, which is what makes the panel's dimensions independent of the source's square aspect ratio.
2. A uniform tint overlay div, `absolute inset-0`, `aria-hidden="true"`, background `color-mix(in oklch, var(--color-bg) 35%, transparent)` — lighter than the hero scrim, just enough to make the button pop.

**Script.** A scoped `<script define:vars={{ videoId, titleForA11y }}>` at the bottom of the component. Query `.facade-container`, then `[data-facade-trigger]` within it, both with optional chaining. Attach a click listener with `{ once: true }`. Inside the handler, synchronously and with no `await`, `setTimeout` or promise: create an iframe element, set `src` to the nocookie embed URL built as a template literal from `videoId` with `?autoplay=1`, set `title` to `titleForA11y`, set `allow` to `autoplay; encrypted-media; picture-in-picture`, set `allowFullscreen` true, set `referrerPolicy` to `strict-origin-when-cross-origin`, set `className` to `absolute inset-0 h-full w-full border-0`, then call `replaceChildren` on the container with it. Synchronous creation inside the handler is what preserves the user gesture; the `allow` attribute is what extends that gesture to the cross-origin child frame. Both values arrive via `define:vars` from typed build-time constants — never string-template them into the script body, and never read them from the DOM or the URL.

**global.css** — add two rules, no removals. `.facade-play:hover { box-shadow: 0 0 32px color-mix(in oklch, var(--color-accent) 50%, transparent), 0 0 64px color-mix(in oklch, var(--color-accent) 25%, transparent); }` and `.facade-play:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 4px; }` — the wider offset is deliberate, a circular button needs the ring off its edge. Do not touch `scripts/check-contrast.mjs`; the accent-on-bg pair used here is already one of its nine verified entries.

Import `Play` from `@lucide/astro`. Do not add a Preact island, a `client:*` directive, or any new dependency.
