## API Coverage — Listmonk public subscription API

| Capability | Used? | Decision |
|-----------|-------|----------|
| `POST /api/public/subscription` with `email` + `list_uuids` | **Used** | The single call this phase makes (D-05) |

| Captcha / ALTCHA on this endpoint | **Not available** | Verified from Listmonk source: `PublicSubscription` has no captcha hook. Mitigation moves to honeypot + proxy rate limiting (04-02). |
| `POST /subscription/form` (hosted HTML form path) | **Not used** | It does enforce ALTCHA, but switching to it would abandon the in-page no-reload UX FAN-02 requires. |
| Any other Listmonk API surface (admin, subscribers, campaigns) | **Not used** | Requires an API key; nothing in this phase authenticates. |
