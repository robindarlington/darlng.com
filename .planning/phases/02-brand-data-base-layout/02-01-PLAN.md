    Add two guards beyond the researched version, because BRAND-02 requires the gate to stay honest as the accent is re-tinted for future releases:

    Guard A — token presence. Read `website/src/styles/global.css` through `node:fs` with the path resolved from `import.meta.url` (so the script works regardless of cwd) and, for every distinct hex the pair table references, assert that hex appears in the stylesheet compared case-insensitively in 6-digit `#RRGGBB` form. Print the name of any hex that is not found and exit 1. This is what makes a re-tint that updates the CSS but not the script a hard failure rather than a stale green.

    Guard B — non-vacuous table. Assert the pair table has exactly 9 entries; if it has 0 or fewer than 9, print the count and exit 1. An empty table must never exit 0.

    Output format: exactly one line per pair, beginning with `PASS ` or `FAIL `, then the pair label, then the computed ratio to two decimals and the required minimum. Nothing else on stdout when everything passes. Exit 1 if any pair fails or either guard trips, 0 otherwise. Import only `node:fs` and `node:path` builtins — add no package dependency for this script.

    Then wire it into `website/package.json`: add `"check:contrast": "node scripts/check-contrast.mjs"` and change `"check"` from `"astro check"` to `"astro check && npm run check:contrast"`. Leave `"build"` as exactly `"astro build"` — the Dockerfile build stage from Phase 1 must stay unaffected.
